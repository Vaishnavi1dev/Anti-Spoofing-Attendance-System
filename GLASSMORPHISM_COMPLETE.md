### Customization

Want to adjust the glass effect? Edit these values in `Login.tsx`:

**More transparent (show more background):**
```tsx
className="bg-black/30 backdrop-blur-2xl"
```

**Less transparent (more readable):**
```tsx
className="bg-black/50 backdrop-blur-xl"
```

**Stronger blur:**
```tsx
className="bg-black/40 backdrop-blur-3xl"
```

**Lighter blur:**
```tsx
className="bg-black/40 backdrop-blur-lg"
```
