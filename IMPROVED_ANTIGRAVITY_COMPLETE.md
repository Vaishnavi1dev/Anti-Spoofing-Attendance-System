## 🔧 Customization

Want to adjust? Edit `AntigravityBackground.tsx`:

**More particles:**
```tsx
count={200}
```

**Stronger repulsion:**
```tsx
magnetRadius={300}
fieldStrength={0.8}
```

**Different color:**
```tsx
color="#00D9FF"  // Cyan
color="#00FF88"  // Green
color="#FFD700"  // Gold
```

**Faster animation:**
```tsx
waveSpeed={0.04}
rotationSpeed={0.002}
```
